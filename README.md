# Search App

React class component search application.

## What it does

- You can search for characters
- The last search is saved
- Results show character name and description
- Spinner appears while data is loading
- Error message appears if request fails
- There is a test button for checking the error boundary

## API

The app uses Jikan API:

```txt
https://api.jikan.moe/v4/characters
```
